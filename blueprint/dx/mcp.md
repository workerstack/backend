# dx — the mounted MCP endpoint

`mcp()` serves an app's operations as MCP tools at a fixed path. The generated MCP server's own options (tools, output schema, annotations, results) are honey-clients's: https://github.com/workerstack/clients/blob/main/docs/codegen.md.

| value | required | default | outcome | pitfall | test |
| --- | --- | --- | --- | --- | --- |
| `mcp(app, path, handler, options?)` | — | — | **[bit 21]** mounts the generated MCP handler on the app from `@lovrozagar/honey/mcp`: POST only (GET/DELETE 405), under the app's middleware and basePath, kept out of the document and the tool set; tool calls dispatch in-process through `app.fetch` | the subpath, not the root, so an app that serves no MCP bundles none of it | `mcp/mount.test.ts` |
| `authenticate(request, ctx)` | when any mounted tool's operation declares security | — | **[bit 21]** runs before any dispatch; `false` answers HTTP 401 with `WWW-Authenticate`; returns a boolean only, so no principal travels and the inner routes re-check the forwarded credential | a secured tool set mounted without it throws at mount time; there is no opt-out | `mcp/mount.test.ts` |
| `codegen.mcp` | — | off | **[bit 21]** the plugin output that writes the mounted handler (an entry plus its companion directory); `true`, a path or an object | the standalone stdio/HTTP server still comes from `honey-clients generate` | `build/config.test.ts` |
| `oauth(options)` | — | off | **[bit 21]** from `@lovrozagar/honey/mcp/oauth`, passed as `mcp()`'s `oauth`: serves the protected-resource metadata (path-inserted, RFC 9728) and answers 401 with `Bearer resource_metadata` and an inner insufficient_scope with one 403 step-up naming the route's scopes | the resource-server half only (no AS, no token validation; `authenticate` still decides); refused at call time: no servers, a non-https issuer, `offline_access`, an invalid scope | `mcp/oauth.test.ts` |
| `uploads(options)` | — | off | **[bit 21]** from `@lovrozagar/honey/mcp/uploads`, passed as `mcp()`'s `uploads`: a file too large to inline is PUT out of band to `<path>/uploads/<token>` and the call retried; the token is one-shot (an atomic claim), scoped to the call, expiring (`ttlMs` 10 min) and bound to an HMAC of the caller's credential | a rotated credential (an OAuth refresh) within the TTL refuses the claim; the store's claim must be atomic (D1 or a Durable Object, never KV) | `tests/integration/mcp-files.test.ts`, `tests/integration/security/mcp-uploads-adversarial.test.ts` |
| `memoryUploadStore()` | — | — | **[bit 21]** an in-memory `UploadStore` (`claim`, `put`, `take`) for one process | not shared across Workers isolates or instances; production uses a store with an atomic claim | `tests/integration/mcp-files.test.ts` |
| `urlFiles(options)` | — | off | **[bit 21]** from `@lovrozagar/honey/mcp/url-files`, passed as `mcp()`'s `urlFiles`: a file argument may be an https URL on a listed host, fetched with a streamed cap and a timeout | hosts by exact name (or an explicit `*.`); IP literals refused; no redirect is ever followed; DNS is not resolved, so list only hosts you control | `tests/integration/security/mcp-url-files-adversarial.test.ts` |
